# Brag Plan: FormBhar

## What is this app?
FormBhar is an AI-powered Google Forms auto-filler Chrome Extension (Manifest V3) that contextually answers questions and handles multi-page forms automatically using GPT-4o, Gemini, or Claude.

## The angle
The end of manual Google Form entry forever. Instead of copying and pasting or typing the same personal details 50 times, FormBhar reads the form, reasons about the context, and autofills every page instantly.

## Hook (first 2-3 seconds)
A giant counter reading "2,491 Google Forms Filled" slamming onto screen over a sleek dark glassmorphism background with the headline: "NEVER FILL A FORM AGAIN."

## Key moments (the middle)
1. **The Floating Action Stack**: The signature Glassmorphism buttons (`✨ Auto-Fill with AI`, `💬 Use ChatGPT (No Quota)`, `👤 Fill Profile Data`) hovering inside Google Forms.
2. **Contextual AI Answer Engine**: Multi-choice, short answer, and reasoning questions getting populated live with 100% precision.
3. **Smart Multi-Page & Autonomous Mode**: Clicking "Next" automatically fills page 2 in the background with zero user interaction.

## Outro / punchline
"Stop typing. Start submitting." -> FormBhar logo reveal & GitHub link.

## User flow worth showing
Open Google Form -> Click "Auto-Fill with AI" -> Form fills automatically -> Click Next -> Page 2 fills automatically.
